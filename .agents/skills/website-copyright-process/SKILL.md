# 网站软著流程 Skill

## 概述

本 Skill 提供中国版权保护中心（https://www.ccopyright.com.cn/）网站软件著作权登记的全流程指导，包含申请准备、在线填报、材料提交、进度跟踪等完整步骤。

## 适用场景

当用户需要：
- 为网站或 Web 应用申请软件著作权
- 了解中国版权保护中心的登记流程
- 准备软著申请材料
- 跟踪申请进度
- 处理软著相关变更、转让等业务

## 核心流程

### 1. 申请前准备

#### 1.1 确定申请主体
- **个人申请**：身份证、护照等有效证件
- **企业申请**：营业执照（加载统一社会信用代码）
- **事业单位/社团法人**：相应法人证书
- **外国机构**：需办理附加证明书或使领馆认证

#### 1.2 准备软件材料
- **软件名称**：准确、规范，体现软件功能
- **版本号**：如 V1.0、V2.0 等
- **开发完成日期**：软件实际开发完成时间
- **首次发表日期**：首次公开或发布的时间

#### 1.3 准备鉴别材料
- **源程序**：前、后各连续30页（共60页）
  - 不足60页提交全部
  - 每页不少于50行
  - 包含程序开头和结尾
- **文档材料**：前、后各连续30页（共60页）
  - 设计文档、用户手册、操作说明等
  - 每页不少于30行

### 2. 在线申请流程

#### 2.1 账号注册与实名认证
1. 访问 https://www.ccopyright.com.cn/
2. 点击"注册"创建账号
3. 完成实名认证（上传身份证明文件）

#### 2.2 填报申请信息
1. 登录后选择"软件登记"
2. 在线填写《计算机软件著作权登记申请表》
3. 主要填写内容：
   - 软件基本信息
   - 著作权人信息
   - 开发方式（独立/合作/委托/下达任务）
   - 权利取得方式（原始取得/继受取得）
   - 权利范围

#### 2.3 上传申请材料
1. **申请确认签章页**：在线打印→签字盖章→扫描为PDF
2. **身份证明文件**：营业执照/身份证扫描件
3. **鉴别材料**：源程序和文档的PDF文件
4. **权利归属证明**（如适用）：
   - 委托开发合同
   - 合作开发合同
   - 任务书或下达任务文件

### 3. 提交与审查

#### 3.1 提交申请
1. 确认所有材料无误
2. 在线提交申请
3. 系统生成申请流水号

#### 3.2 审查流程
1. **受理审查**（1-3个工作日）
   - 材料齐全：予以受理
   - 材料问题：补正通知（30日内补正）
   - 不予受理情形：重复申请、软件被查封等

2. **实质审查**（60日内）
   - 符合规定：予以登记
   - 需要补正：补正通知（30日内补正）
   - 不符合规定：不予登记

### 4. 获取证书

#### 4.1 电子证书
- 审查通过后，在用户中心下载电子证书
- PDF格式，含电子签章
- 支持本地验签和在线验签

#### 4.2 证书验证
- **本地验签**：用PDF阅读器打开，点击印章查看签名属性
- **在线验签**：通过第三方平台验证证书真伪

## 常见问题

### Q1: 网站可以申请软著吗？
可以。网站作为计算机软件的一种表现形式，只要具备独创性，就可以申请软件著作权。

### Q2: 需要提交全部源代码吗？
不需要。只需提交前、后各连续30页的源程序（共60页），如果整个程序不足60页，则提交全部。

### Q3: 软著申请费用是多少？
目前软件著作权登记已停征费用，免费办理。

### Q4: 申请需要多长时间？
从提交到获得证书，正常情况需要2-3个月，具体时间取决于审查进度。

### Q5: 电子证书和纸质证书有什么区别？
电子证书与纸质证书具有同等法律效力，且更方便保存和验证。

## 使用指南

### 快速开始
1. 使用本 Skill 时，先说"我需要申请网站软著"
2. 按照提示准备相应材料
3. 使用模板整理申请材料
4. 在线填报时参考填写说明

### 注意事项
1. **材料真实性**：所有提交材料必须真实有效
2. **格式要求**：PDF格式，内容清晰可辨
3. **补正及时性**：收到补正通知后30日内必须完成补正
