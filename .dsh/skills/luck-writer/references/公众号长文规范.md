# 幸知公众号长文规范

> 原 `skills/luck-wechat-writer/SKILL.md`（公众号专项规范）。
> 2026-08-14 SKILL 清算时吸收进 `luck-writer/references/`，luck-wechat-writer 已归档至 `99_Archive/skills-archived/`。
> 本文件是 luck-writer 公众号适配层的唯一规范源。

## 版式规则（关键——解决固化问题）

- **禁止使用 `---` 分割线**。微信公众号不是 Markdown 渲染器，水平线在手机端生硬割裂，破坏阅读沉浸感。段落之间靠内容自然过渡。
- **标题层级仅用两类**：文章主标题（`#`）和小节标题（`##`）。不用 `###` 及更深层级——手机屏幕太窄，三层嵌套看起来很碎。
- **引言不要用 `>` blockquote**。日期和一句话价值锚直接写成一个短段落就好，不要套引用格式。
- **小节标题之间不要空行过多**。手机端一个空行就够了，两个以上会显得松散。
- **引导关注语写在正文最后一段**，不单独一行"关注我"，不和署名之间用水平线分隔。直接连着正文，用换行隔开署名即可。

## 写作顺序

```
# [标题：激发好奇心或价值主张，不剧透结论]

（日期 + 一句话价值锚写成一个短段落，不用 > blockquote）

（100-150字引入，用一个事实/数据/场景把读者拉进来，不用"最近XX很火"开头）

## 第一个小节标题

（核心论点展开）

## 第二个小节标题

（继续展开。至少包含：一处反向视角 + 一处结构归因 + 一处时间拉伸）

（延续自然分节，不强制小节数量）

（100-150字收尾，不总结观点，给一个可带走的问题或行动。收尾之后自然接引导关注语，用换行隔开署名。）

*幸知 / 日期 / 信源*
```

## 引导关注（强制）

每篇文章末尾（署名之前）必须有引导关注语。1-2句话，风格与正文一致。**直接写在最后一个正文段落里**，不要单独标成"引导关注"小节。禁止：单独一行"关注我"、"点赞转发在看"三连、超过 2 句。语气：像在跟已经读了全文的读者自然对话，不是广告位。

## 公众号补充禁止清单

- 禁止"最近XX很火""随着XX的发展"（信息量为零的开头）
- 禁止"有人认为A...也有人认为B...各有各的道理"（没有态度的和稀泥）
- 禁止没有案例的抽象观点（每观点配至少一个具体参照）
- 禁止结尾用"让我们一起期待"（假大空收束）
- 禁止不标注时间的案例引用
- 禁止抛出术语不给解释——OODA、贝叶斯、飞轮、benchmark 等等，第一次出现必须用一句话讲清楚（"说白了就是……"）。读者是刷手机的人，不是你的同行。

## 节奏补充（公众号特化）

- **引用不引用**：数据融在句子里，不单独做成引用块。信源标注在文末，不在文中打断阅读。
- **顺着事实推进**：写清事件、动作和后果；反例确实影响判断时再展开，不按段落强制安排转折。
