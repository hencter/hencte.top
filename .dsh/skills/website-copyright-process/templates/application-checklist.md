# 网站软著申请检查清单

## 申请前检查

### 1. 基本信息确认
- [ ] 软件名称已确定（中英文均可）
- [ ] 版本号已确定（如 V1.0）
- [ ] 开发完成日期已确认
- [ ] 首次发表日期已确认（如未发表可不填）
- [ ] 著作权人信息准确完整

### 2. 申请主体材料
- [ ] 企业：加载统一社会信用代码的营业执照
- [ ] 个人：有效身份证件
- [ ] 事业单位：事业单位法人证书
- [ ] 外国机构：认证文件及中文翻译

### 3. 软件材料准备
- [ ] 源程序前30页（每页不少于50行）
- [ ] 源程序后30页（每页不少于50行）
- [ ] 文档材料前30页（每页不少于30行）
- [ ] 文档材料后30页（每页不少于30行）
- [ ] 材料页眉包含软件名称和版本号

## 在线填报检查

### 4. 账号准备
- [ ] 已注册中国版权保护中心账号
- [ ] 已完成实名认证
- [ ] 登录信息已保存

### 5. 申请表填写
- [ ] 软件基本信息准确
- [ ] 著作权人信息完整
- [ ] 开发方式选择正确
- [ ] 权利取得方式正确
- [ ] 权利范围描述清晰

### 6. 材料上传
- [ ] 申请确认签章页已签字盖章
- [ ] 申请确认签章页已扫描为PDF
- [ ] 身份证明文件清晰可辨
- [ ] 鉴别材料格式正确（PDF）
- [ ] 权利归属证明（如需要）已准备

## 提交前最终检查

### 7. 格式检查
- [ ] 所有文件均为PDF格式
- [ ] 文件大小适中（不超过系统限制）
- [ ] 内容清晰，无反光、无遮挡
- [ ] 文字方向正确（纵向排版）

### 8. 内容一致性检查
- [ ] 申请表中软件名称与鉴别材料一致
- [ ] 申请表中版本号与鉴别材料一致
- [ ] 著作权人信息与身份证明文件一致
- [ ] 开发完成日期与实际相符

### 9. 完整性检查
- [ ] 所有必填项已填写
- [ ] 所有必传文件已上传
- [ ] 申请材料已留存副本
- [ ] 联系人信息准确

## 提交后跟踪

### 10. 进度跟踪
- [ ] 记录申请流水号
- [ ] 定期登录系统查看进度
- [ ] 关注站内信通知
- [ ] 准备应对可能的补正要求

### 11. 补正处理（如需要）
- [ ] 收到补正通知后30日内完成
- [ ] 按要求补充或修改材料
- [ ] 重新上传补正材料
- [ ] 确认补正已提交

### 12. 证书获取
- [ ] 登录用户中心下载电子证书
- [ ] 验证电子证书有效性
- [ ] 保存证书到安全位置
- [ ] 必要时打印纸质证书

## 常见问题预防

### 材料问题预防
- [ ] 避免使用截图代替源程序
- [ ] 确保文档材料有实际内容
- [ ] 检查文件是否损坏或无法打开
- [ ] 确认PDF文件可正常显示

### 填报问题预防
- [ ] 避免使用特殊字符
- [ ] 版本号格式统一（如都带V或不带V）
- [ ] 日期格式正确（YYYY-MM-DD）
- [ ] 联系方式准确有效

### 流程问题预防
- [ ] 不要重复提交相同申请
- [ ] 及时处理补正通知
- [ ] 保存所有沟通记录
- [ ] 记录重要时间节点
