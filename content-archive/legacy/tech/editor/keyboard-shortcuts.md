## VS Code

你只需要在 VS code 中按下 <kbd>Ctrl</kbd>+<kbd>K</kbd> <kbd>Ctrl</kbd>+<kbd>R</kbd>
就会自动在浏览器里面打开你当前系统的按键绑定。
