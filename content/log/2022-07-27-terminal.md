> **修订说明（2026 年 11 月）**：这篇笔记最初写于 2022 年。旧示例的 `ms-appdata` 路径里多了一个空格，会导致图标无法正确定位；这里修正了路径，并补充配置位置。

## 1. 把图标放进可访问的目录

使用 Microsoft Store 常规安装的 Windows Terminal 时，可以把 `kali.ico` 放在：

```text
%LOCALAPPDATA%\Packages\Microsoft.WindowsTerminal_8wekyb3d8bbwe\RoamingState\kali.ico
```

这是 Windows Terminal 文档给出的 `ms-appdata:///roaming/` 对应目录。不同安装渠道或版本的配置文件位置可能不同，别把这个路径视为所有发行方式的通用目录。

## 2. 在 settings.json 中引用图标

打开 Windows Terminal，按 `Ctrl + ,` 进入设置。可以使用图形化设置，也可以打开 JSON 配置，找到需要修改的配置文件（profile），添加：

```json
"icon": "ms-appdata:///roaming/kali.ico"
```

这里的 `icon` 是**某个 profile 的属性**，不能随意放在配置文件顶层。原文曾误写成 `ms-appdata:///roaming/ kali.ico`，其中 `kali.ico` 前的空格是错误的。

## 3. 没有显示时检查

- 图片名称是否和配置中的路径完全一致。
- `icon` 是否写在预期的 profile 下。
- 图片是否真的放在当前安装方式对应的目录中。

图标也可以使用受支持的绝对路径，不一定非要使用 `ms-appdata`。选择适合自己同步与备份习惯的方式即可。
