## 核心插件（已启用）

| 插件 | 说明 |
| --- | --- |
| 文件浏览器（`file-explorer`） | 管理文件树、移动/重命名笔记与目录。 |
| 全局搜索（`global-search`） | 跨笔记全文搜索，用于快速定位信息。 |
| 快速切换（`switcher`） | 类似 `Ctrl+O` 的快速打开/切换笔记入口。 |
| 图谱（`graph`） | 观察链接网络，用于探索与复盘结构。 |
| 反向链接（`backlink`） | 查看哪些笔记链接到当前笔记，补全上下游关系。 |
| Canvas（`canvas`） | 用卡片与连线组织想法，适合流程、结构化梳理。 |
| 出链（`outgoing-link`） | 查看当前笔记指向哪些链接/笔记，便于检查引用。 |
| 标签面板（`tag-pane`） | 按标签浏览与过滤内容。 |
| 属性（`properties`） | 使用属性/元数据做结构化管理，支持筛选与检索。 |
| 页面预览（`page-preview`） | 悬停预览链接内容，减少跳转成本。 |
| 每日笔记（`daily-notes`） | 按日期生成日记/日志入口。 |
| 模板（`templates`） | 用模板快速插入固定结构内容。 |
| 笔记编辑辅助（`note-composer`） | 抽取选中内容为新笔记、合并笔记等编辑操作。 |
| 命令面板（`command-palette`） | 搜索并执行命令，统一入口。 |
| 编辑器状态（`editor-status`） | 显示光标位置、字数等状态信息。 |
| 书签（`bookmarks`） | 收藏常用笔记/搜索/块引用，减少重复查找。 |
| 大纲（`outline`） | 基于标题的目录导航与结构预览。 |
| 字数统计（`word-count`） | 统计当前笔记字数/阅读量指标。 |
| 文件恢复（`file-recovery`） | 恢复最近删除或异常丢失的文件。 |
| 同步（`sync`） | Obsidian Sync 同步能力开关。 |
| Bases（`bases`） | 基于属性的表格/集合视图，用轻量方式做数据化管理。 |
